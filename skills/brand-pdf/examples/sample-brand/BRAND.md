# Sample brand pack

This is a fictional example, not an existing customer or product.

- Source tokens: `tokens.css`; shared component grammar: `components.css`.
- Body type uses the system serif stack; headings use the system sans-serif stack.
  No web font, logo, external asset, credential, or account is required.
- Paper, ink, accent, rule, and spacing values come from token custom properties.
- Report tables reuse `.register`; metadata uses `.document-meta`.
- Letter paper, 0.75-inch body margins. `report.html` contains two flowing pages
  with a deliberate page break; page numbers are generated by CSS counters.

For a real brand, import its actual token/font/component source files and replace
this document with exact paths, required theme attributes, and approved usage.
Never silently substitute this sample palette for the user's brand.
